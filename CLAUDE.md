# Repository instructions

## Organization API standard

Before creating or changing an HTTP API, its client, OpenAPI or examples, read and follow the [organization API standard](https://github.com/good-people-inc/ai-artifacts/blob/main/rules/general/api.md). It is the shared source of truth; do not copy or redefine it here.

The shared API standard is maintained in ai-artifacts, not duplicated here. API-related PRs describe the contract change, consumers, compatibility, rollout and validation.
